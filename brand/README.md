# Brand Guidelines - Eduly

Este diretório contém todos os recursos e informações sobre a identidade visual da marca Eduly.

## Estrutura

- `brand-data.ts` - Dados completos da marca (cores, tipografia, valores, etc.)
- `README.md` - Este arquivo com informações sobre a marca

## Cores Principais

- **Primary**: `#1e40af` (Azul escuro)
- **Secondary**: `#6366f1` (Índigo)
- **Background**: `#f0f9ff` (Azul muito claro)

## Logo

A logo principal está localizada em:
- Login: `assets/images/eduly_logo_login.png`
- Principal: `assets/images/eduly_logo.png`
- Ícone: `assets/icon.png`

## Uso

Para usar os dados da marca em seus componentes, importe:

```typescript
import { BrandData } from '@/brand/brand-data';
```

## Design System

O design do app segue um padrão moderno com:
- Cards arredondados (borderRadius: 12-24px)
- Sombras suaves
- Gradientes azuis/índigo
- Tipografia clara e legível
